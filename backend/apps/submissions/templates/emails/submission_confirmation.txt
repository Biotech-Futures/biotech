Plain-text alternative, written as text rather than derived from the HTML.

Deriving it with strip_tags() looked equivalent but was not: strip_tags removes
tags and keeps whatever sat between them, so everything inside the base
template's <style> block arrived as visible CSS above the message. Most clients
render the HTML part and never show this, but those that fall back to text —
and some screen readers — would have read out the stylesheet first.

Keep the wording here in step with submission_confirmation.html.
